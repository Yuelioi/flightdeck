# Keep private reference material out of durable artifacts

Permission to inspect another project as design input is not permission to publish its identity.
Anything committed to a repository may later be pushed, packaged, indexed, or quoted outside the
original conversation.

When durable writing draws on a user-supplied reference project:

- use neutral labels such as “reference project A”;
- retain only portable structural facts needed for the conclusion;
- omit names, repository paths, URLs, and distinctive private terminology;
- review commit messages, Work documents, Knowledge, specifications, and public docs before commit.

Keep identifying detail only when the user explicitly asks for it in that durable output.
