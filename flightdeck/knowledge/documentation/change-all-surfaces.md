# Change every user-facing surface together

A product change is incomplete when the implementation or skill says one thing while READMEs,
examples, host manifests, installed artifacts, or contributor guidance still describe the old
contract.

After a structural change, search the whole repository for retired terms and paths. Keep one shared
skill tree when hosts have no real behavioral difference, validate each host manifest, and inspect
the installed artifact rather than only the source. Read the primary examples as a new user would.
Keep translations aligned with the same product meaning rather than treating them as historical
snapshots.
