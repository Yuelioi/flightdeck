```markdown
## DO NOT pre-read to "match style" — the script is the authority

This skill stamps frontmatter, naming, and location; you supply only the body. Pre-reading sibling artifacts to "match format/style" is exactly the hand-derivation this skill exists to eliminate. These thoughts mean STOP:

| Thought | Reality |
|---------|---------|

| "I'll read the INDEX to match the format" | INDEX is regenerated by the script — you NEVER hand-align it. |
| "Let me check an archived spec for house style" | Body prose style is free-form; there is NO fixed template to pre-match. |

**You MUST NOT Read sibling artifacts or INDEX files to align format, style, or naming before invoking this skill.** The ONLY legitimate pre-reads are:
- The **content** you are encoding into the body (usually already in hand from brainstorming / the task).
- **Incident dedup** — before creating an `incident`, grep the error text / run `--match-signature` to check for an existing signature (required by the incident contract below; this is NOT format-matching).
```
