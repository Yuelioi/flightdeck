# Define Knowledge file and subject organization

## Outcome

Knowledge remains easy to find and maintain through ordinary paths and prose without a fixed
taxonomy, index, schema, or metadata catalog.

## Current

Each Knowledge file owns one independently searchable and applicable practice. Subject folders use
natural project search terms and grow organically. Guidance splits when its parts can be selected or
changed independently and stays together when it must be understood as one practice. There is no
fixed taxonomy, index, registry, or metadata catalog.
