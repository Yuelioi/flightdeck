# Define when Work promotes Knowledge

## Outcome

A producing Work has a small maturity test that promotes durable operating guidance without turning
every lesson, observation, or local workaround into project Knowledge.

## Current

A Work promotes a conclusion only when current evidence verifies it, another independent Work is
reasonably likely to benefit, and the conclusion can be rewritten as self-contained
project-specific positive guidance. A second observed occurrence is useful evidence but not a
mechanical prerequisite.
