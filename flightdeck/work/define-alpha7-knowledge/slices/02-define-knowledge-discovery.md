# Define how Work discovers Knowledge

## Outcome

A Work has one bounded trigger and lookup path for finding relevant Knowledge without eager loading
or machine routing metadata.

## Current

Work discovers Knowledge only when its current action raises a project-specific practice question.
It reads relevant Knowledge already linked by the Work first; otherwise it searches only the
applicable subject, filenames, and headings. Routine recovery does not scan or preload Knowledge.
