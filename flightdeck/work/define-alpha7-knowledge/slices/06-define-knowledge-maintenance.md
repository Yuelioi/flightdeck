# Define how stale Knowledge is maintained

## Outcome

A Work that encounters guidance contradicted by current reality has a concrete repair path without
adding status fields, recheck ledgers, or a parallel maintenance system.

## Current

A Work that finds Knowledge contradicted by current reality owns immediate containment. It rewrites
verified replacement guidance; if only the old claim is disproven, it removes that material and
carries unresolved research in Work. Knowledge keeps no stale marker, version, or recheck state;
Git retains history.
