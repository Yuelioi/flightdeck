# Continue work

Recover from the repository, not from assumed chat history.

1. Resolve the Work in this order: an exact Work named by the user, the valid deck Focus, or the
   only Work whose Status is Open. If several remain plausible, show their titles, statuses, and
   Next actions and ask the user to choose.
2. Read the selected `index.md` and `context.md` completely.
3. If `plan.md` exists, read its low-resolution order and completion state. Follow only the zero
   through three local links written into Next; this normally opens the current Slice or immediate
   material. Keep other Slices, References, Knowledge, and Work lazy.
4. Inspect live Git status and the files relevant to Next. Do not assume the handoff is newer than
   the working tree.
5. Summarize Goal, Current, Next, important constraints, and uncommitted state. Note any stale or
   missing link plainly.
6. Perform the main skill's bounded Knowledge check for the current action. Treat selected guidance
   as advisory.
7. Continue with the Next action unless the user asked only to inspect or list resumable work.

The deck contains only Open Work. Finished and Stopped Work remains at its stable path and is opened
only when named or relevant as history.
