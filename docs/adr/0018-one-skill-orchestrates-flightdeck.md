# One skill orchestrates Flightdeck

Flightdeck ships one orchestration skill with progressively loaded branches for start, continue,
save, close, specialist output routing, and optional Wayfinding, plus Markdown templates for Deck,
Work, Context, Plan, and Slice. A short repository instruction activates this contract for durable
work; Flightdeck does not fork specialist skills merely to redirect output and does not restore a
runtime, CLI, schema, or generator.
