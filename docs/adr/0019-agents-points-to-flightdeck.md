# AGENTS points durable work to Flightdeck

Creating the first durable Work ensures the repository root `AGENTS.md` contains one short,
provider-neutral Flightdeck entry that directs recovery through the installed skill and applies the
Work Output Contract to specialist outputs. The repository file does not duplicate plugin rules,
create provider wrappers, or transfer ownership of an existing root `CONTEXT.md` to Flightdeck.
