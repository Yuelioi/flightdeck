# Supported output routing

Flightdeck routes Work-scoped domain modeling into `context.md`, research and specs into descriptive
files under `references/`, and ticketing or Wayfinding into `plan.md` plus only the Slices that need
independent recovery. Handoff is replaced by saving the Work, execution skills update source and
the current Slice, and prototypes or required assets remain near their owning code and are linked;
project-wide vocabulary and ADRs alone use the repository root conventions. References stay flat
until real volume justifies a subject directory, and supported skills do not create a second task
or handoff store.
