# Version 3 alpha remains Markdown-only

The Markdown redesign continues the published Version 3 alpha line rather than treating abandoned,
unreleased runtime experiments as Version 4 or 5 product generations. It remains a plugin of
manifests, one orchestration skill, progressively loaded instructions, templates, and documentation,
with no production runtime, CLI, MCP server, schema, generator, hidden state, or required validator.
