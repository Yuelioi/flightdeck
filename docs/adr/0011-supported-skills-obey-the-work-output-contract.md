# Supported skills obey the Work Output Contract

Flightdeck is the orchestration entry for supported document-producing skills and routes their
Work-scoped context, decisions, research, specs, and execution breakdown into the owning Work.
Outputs that inherently belong to source code, a temporary location, an external system, or an
unsupported third-party contract stay at their natural location and are linked, so physical
unification is guaranteed inside the supported boundary without copying fallback artifacts.
