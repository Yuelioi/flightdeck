# Upgrades use AI judgment, not version compatibility

Alpha.7 does not ship version detectors, schemas, scripts, or guaranteed migration paths for rapidly
changing pre-release formats. A progressively loaded upgrade guide tells the AI to inspect actual
documents and Git, classify their semantic roles against the current Work model, preserve ambiguous
material, ask before irreversible choices, and prove the resulting fresh-session recovery; it does
not mechanically rename directories or automatically commit.
