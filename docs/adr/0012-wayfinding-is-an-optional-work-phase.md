# Wayfinding is an optional Work phase

When a Work Goal is clear but the route is not, its Plan may resolve one Decision Slice at a time
and retain unformulated in-scope uncertainty under `Not yet specified`; later Delivery Slices use
separate completion items. Flightdeck absorbs Wayfinder's fog, frontier, readable-name, and method
selection practices but rejects its separate Map, ticket lifecycle, labels, claims, blocking graph,
and automatic Tracker or branch operations.
